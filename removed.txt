# Spid3r — Removed Non-Language Subsystems (2026-11-22)

This file lists everything removed from the Spid3r repository so presentations,
slides, and external documentation can be updated accurately.

## 1. Removed Subsystems (6 Total)

1. Bare-Metal OS Kernel (`kernel/` / Spid3rOS / R13 / DP-8)
   - Deleted directory: `kernel/` (`x86_64-unknown-none` `no_std` kernel crate, `link.ld`, `init/init.matrix`)
   - Removed CLI command: `spid3r kernel build`
   - Removed CI job: `kernel` in `.github/workflows/ci.yml`
   - Removed docs/diagrams: `docs/OS_TRACK.md`, `docs/diagrams/os-baremetal.svg`

2. OCI Container Runtime (`src/oci/`, `src/container/`, `src/native/sys.rs` / R11 / DP-7)
   - Deleted directories/files: `src/oci/`, `src/container/`, `src/native/sys.rs`
   - Removed Cargo feature: `container`
   - Removed CLI command: `spid3r container <pull|create|start|run|stop|kill|rm|ps|inspect|logs|gc>`
   - Removed tests/fuzz/CI: `tests/oci_container_tests.rs`, `fuzz/fuzz_targets/fuzz_oci_manifest.rs`, `container` CI job
   - Removed docs/diagrams: `docs/CONTAINERS.md`, `docs/diagrams/containers-oci.svg`

3. Remote Management Agent & Paired-Device Daemon (`src/agent/` / `spid3r-agent/1`)
   - Deleted directory: `src/agent/`
   - Removed CLI commands: `spid3r agent ...`, `spid3r admin ...`
   - Removed `spid3r control` subcommands/tabs: `agent`, `devices`, `pair`, `ops`, `audit`, `remote`
   - Removed config section & keys: entire `[agent]` section (11 keys) + `security.allow_remote`
   - Removed fuzz target: `fuzz/fuzz_targets/fuzz_agent_frame.rs`
   - Removed docs/diagrams: `docs/AGENT.md`, `docs/diagrams/runtime-management.svg`

4. ML / DataFrame / Redis / SSH Standard Library Extras
   - Deleted stdlib modules (`.matrix`): `stdlib/ml.matrix`, `stdlib/dataframe.matrix`, `stdlib/ssh.matrix`
   - Deleted native stdlib driver: `src/stdlib/redis.rs`
   - Removed native builtins (3): `redis_connect`, `redis_command`, `redis_close` (removed from both Rust `src/semantic/mod.rs` and selfhost `selfhost/semantic.matrix`)
   - Deleted examples/corpus: `examples/data_science_pipeline.matrix`, `selfhost/corpus/examples/data_science_pipeline.matrix`

5. Unvetted Hand-Rolled Crypto (`src/crypto/`)
   - Deleted directory: `src/crypto/` (custom ChaCha20 / Poly1305 / AEAD / HKDF module previously used by `src/agent/`)

6. Embedded WASM & Host Plugin System (`src/plugin/`)
   - Deleted directory: `src/plugin/`
   - Removed Cargo feature & dependency: `plugins-wasm` feature and `wasmi` crate
   - Removed CLI command: `spid3r plugin <abi|list|check>`
   - Removed config keys: `modules.plugins`, `modules.allow_wasm`, `modules.allow_host` (and `SPID3R_PLUGINS` env alias)
   - Removed tests/examples: `tests/plugin_abi.rs`, `tests/plugin_api.rs`, `tests/plugin_deny.rs`, `tests/plugin_matrix.rs`, `tests/plugin_wasm.rs`, `examples/plugins/`
   - Removed docs/diagrams: `docs/PLUGINS.md`, `docs/PLUGIN_ABI.md`, `docs/diagrams/host-plugins.svg`, `docs/html/plugin.html`

## 2. Updated Numbers for Slides / Specs

- Built-in `.matrix` stdlib modules: 29 -> 26 (removed `dataframe.matrix`, `ml.matrix`, `ssh.matrix`)
- Built-in native stdlib functions: 257 -> 254 (removed `redis_connect`, `redis_command`, `redis_close`)
- `spid3r.ini` schema keys: 60 keys across 13 sections -> 45 keys across 12 sections
- Optional Cargo features: `gui`, `native`, `tls` (removed `plugins-wasm`, `container`; zero-dependency core with `--no-default-features`)
- Frozen selfhost corpus: 136 programs / 137 files verified in `selfhost/corpus/MANIFEST.sha256`
- Deleted files total: 76 files

## 3. What Was KEPT Intact (Do NOT Remove from Presentation)

- Core compiler & engines: tree-walk interpreter, bytecode VM, LLVM 23 AOT native compiler, WebAssembly target (`wasm32`)
- Self-hosted compiler (`selfhost/`, `spid3r-self`, Stage 1/2/3 bootstrap)
- Generics & monomorphization (`DP-1`), unboxed `list<int>` / `list<float>`, C FFI (`extern fn`)
- Developer tooling: `repl`, `debug`, `fmt`, `doc`, `lsp`, `test`, `bench`, `bundle`, `pack`/`unpack`, package manager (`init`, `install`, `add`, `remove`, `tree`, `verify`, `search`, `publish`)
- Local runtime config & control panel: `spid3r.ini`, `spid3rinfo()`, `spid3r config`, local `spid3r control` (`status`, `safety`, `ini`, `config`, `logs`), and desktop `spid3r-control.exe` (Overview, Language, Safety, Configuration, Logs tabs)
- Desktop GUI runtime (`wry`/`tao`, `spid3r gui`)
- Full-stack web framework (`spid3r_web/`) and remaining 26 stdlib modules (`http`, `web`, `stats`, `smtp`, `ftp`, `toml`, `yaml`, `xml`, `tz`, `unicode`, `uuid`, `semver`, `bigint`, `decimal`, `complex`, `rational`, `mathx`, `event`, `gen`, `fastcgi`, `multipart`, `middleware`, `session`, `testkit`, `assert`, `mock`)
- Remaining database support: SQLite (`db_open`), PostgreSQL (`pg_*`), MySQL (`mysql_*`)
