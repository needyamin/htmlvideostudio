স্পিডার — স্লাইডভিত্তিক বর্ণনা (টেক্সট-টু-ভয়েসের জন্য)
SOURCE: presentation_spid3r_bangla_big.html · মোট ১৯ স্লাইড · প্রতিটি "[[SLIDE n]]" একক স্লাইডের সাথে মিলে।

[[SLIDE 1]]
স্পিডার। একটি আধুনিক, দ্রুতগতির, মেমরি-নিরাপদ প্রোগ্রামিং ভাষা। সম্পূর্ণ রাস্ট দিয়ে তৈরি, শূন্য এক্সটার্নাল ডিপেন্ডেন্সি। ভার্সন v1.1.1। ব্রাউজারে WASM-এ চলে, আবার LLVM দিয়ে নেটিভ AOT-ও করা যায়।

[[SLIDE 2]]
স্পিডার এক নজরে। চারটি ভিত্তি। প্রথম, শূন্য ডিপেন্ডেন্সি — কম্পাইলার, ভার্চুয়াল মেশিন, স্ট্যান্ডার্ড লাইব্রেরি, সব নিজস্ব রাস্ট কোডে। দ্বিতীয়, দুটি ইঞ্জিন — বাইটকোড VM এবং AST ইন্টারপ্রেটার, একশত শতাংশ একই ফলাফল। তৃতীয়, লিক-শূন্য গার্বেজ কালেক্টর — সাইকেল সংগ্রাহক, রেফারেন্স লুপও কখনো মেমরি লিক করে না। চতুর্থ, WebAssembly — ব্রাউজার, Node.js, Deno আর Edge Worker, সবখানে একই ইঞ্জিন। সংখ্যায়: ছয়টি প্রিমিটিভ টাইপ, চল্লিশটি রিজার্ভড কীওয়ার্ড, কুড়ির বেশি ডেটা স্ট্রাকচার, ছাব্বিশটি স্ট্যান্ডার্ড লাইব্রেরি মডিউল।

[[SLIDE 3]]
এক বাইনারি, এক কমান্ড। তিনভাবে ইনস্টল: লিনাক্স ও ম্যাকওএসে install.sh স্ক্রিপ্ট, উইন্ডোজে GUI সেটআপ exe, অথবা Cargo install। একটাই বাইনারি — কোনো রানটাইম ইনস্টল লাগে না, ভিজ্যুয়াল সি প্লাস প্লাসও লাগে না। ফাইল এক্সটেনশন dot matrix। হ্যালো ওয়ার্ল্ড প্রোগ্রাম: fn main, তার ভেতরে println Hello World, language নামে ভ্যারিয়েবল Spid3r, বছর ২০২৬, স্বাগতম বার্তা v1.1.1 সহ, এবং return zero। ডকুমেন্টেশনের প্রতিটি উদাহরণ ব্রাউজারেই Try it Yourself বাটনে চালানো যায়।

[[SLIDE 4]]
একটি কমান্ড spid3r, প্রায় পঁচিশটি সাবকমান্ড। তিনটি গ্রুপ। চালানো ও পরীক্ষা: run, check, repl, debug, lsp, test — যা তিন ইঞ্জিনের পার্থক্য যাচাই করে — এবং bench। বিল্ড ও ডেলিভারি: compile, যা কম্পাইলড বাইটকোড বানায়; build, native exe; gui; bundle; fmt; doc। প্রজেক্ট ও অপারেশন: init, install, add, verify, publish, info, config, control। আর আছে --sandbox — ফাইল, নেটওয়ার্ক, প্রসেস, এনভায়রনমেন্ট, সব বন্ধ করে দেয়, অবিশ্বস্ত কোডও নিরাপদে চালানো যায়।

[[SLIDE 5]]
কোড চলে ছয় ধাপে, তিন ইঞ্জিনে। প্রথম লেক্সার, টোকেন তৈরি করে। দ্বিতীয় পার্সার, AST গাছ বানায়। তৃতীয় সিমান্টিক, টাইপ যাচাই করে। চতুর্থ লোয়ারিং, ডিসুগার করে। পঞ্চম ব্যাকএন্ড, এক্সিকিউশন চালায়। ষষ্ঠ GC, মেমরি ফিরিয়ে নেয়। তিন ইঞ্জিন: Tree ইঞ্জিন, রেফারেন্স ওরাকল; বাইটকোড VM, ষাটটি opcode; LLVM নেটিভ, মেশিন কোড LLVM 23 দিয়ে। তিন ইঞ্জিনের আউটপুট অক্ষরে অক্ষরে হুবহু এক হতে বাধ্যতামূলক।

[[SLIDE 6]]
মডিউল খোঁজার ছয় ধাপ। এক, ইমপোর্টকারী ফাইলের নিজের ফোল্ডার। দুই, SPID3R_PATH পরিবেশ ভেরিয়েবল। তিন, ডট স্ল্যাশ stdlib, বর্তমান ডাইরেক্টরিতে। চার, exe-এর পাশের stdlib ফোল্ডার। পাঁচ, vendor ফোল্ডার। ছয়, বাইনারির ভেতরে এমবেড করা স্ট্যান্ডার্ড লাইব্রেরি। নিয়ম: ডিস্ক সবসময় জয়ী — লোকাল ফাইল আগে পেলে সেটাই ব্যবহৃত হয়। পালানো নিষেধ — ডট ডট, অ্যাবসোলিউট পাথ বা ড্রাইভ লেটার দিয়ে রুটের বাইরে যাওয়া যায় না, সব ইঞ্জিনে একই নিয়ম। শেষ ভরসা: কোনো ফাইল না পেলেও এমবেডেড স্ট্ডলিব থাকায় একক-ফাইল অ্যাপ সবসময় চলে।

[[SLIDE 7]]
বিশ্বাসের সিঁড়ি, T0 থেকে T3। তৃতীয় পক্ষের কোড কতটা ক্ষমতা পাবে, স্পিডার স্পষ্টভাবে চিহ্নিত করে। T0, বিল্ট-ইন স্ট্ডলিব, অপরিবর্তনীয়। T1, নিজের প্রজেক্ট ফাইল। T2, ভেন্ডরড প্যাকেজ, SHA-256 যাচাইকৃত। T3, FFI extern fn, বিশ্বস্ত কোড, শুধু নেটিভ বিল্ডে, স্যান্ডবক্সের বাইরে। বড় সুবিধা: প্যাকেজ ইনস্টল করার সময় কোনো কোড চলে না, Cargo-র মতো বিল্ড স্ক্রিপ্ট নেই।

[[SLIDE 8]]
স্বাক্ষিত প্যাকেজ, হ্যাশ-যাচাইকৃত ও স্বাক্ষরিত। প্যাকেজ জীবনচক্র: add, তারপর tree আর verify, তারপর publish, আর install, সিগমা যাচাইসহ। শৃঙ্খল: SHA-256 হ্যাশ যাচাই আর Ed25519 স্বাক্ষর। একবার প্রকাশিত ভার্সন আর বদলায় না। সেমিভার: caret 1.2, greater-equal 1.2.3, ইকুয়াল 1.2.3। হীরা-ডিপেন্ডেন্সি স্বয়ংক্রিয়ভাবে মিটমাট হয়। verify — vendored ফাইল একটি বদলালেই বিল্ড গেট বাতিল করে। আর ইনস্টলের সময় কোনো কোড চলে না — প্যাকেজ শুধু ফাইল।

[[SLIDE 9]]
স্ক্রিপ্ট থেকে সত্যিকারের dot exe, LLVM 23 দিয়ে। কমান্ড: spid3r build app.matrix -o App.exe --release, সাথে --icon, --subsystem windows, --bytecode, --embed ui, --bundle-runtime। --icon কাস্টম আইকন এমবেড করে। --subsystem windows মানে টার্মিনাল ছাড়া GUI। --bytecode মানে সোর্স কোড ছাড়াই ডেলিভারি। --bundle-runtime মানে স্পিডার ইনস্টল নেই এমন পিসিতেও চলবে। --embed ui দিয়ে UI রিসোর্স একক বাইনারির ভেতরে থাকে। সততা: XOR-অবফাস্কেশন মানে গোপনীয়তা নয়, ক্লায়েন্ট বাইনারিতে সিক্রেট রাখবেন না।

[[SLIDE 10]]
ছয় টাইপ, চল্লিশটি কীওয়ার্ড। int, 64-বিট সাইনড; n সাফিক্স মানে bigint। float, IEEE 754 ডাবল, nan আর inf। bool-এ খালি স্ট্রিং, শূন্য, null, false — এগুলো falsy; কিন্তু খালি লিস্ট truthy। string, ইমিউটেবল UTF-8, র-স্ট্রিং আর নেগেটিভ ইনডেক্সিং। null-এ ?? কোয়ালেসিং আর ?. চেইনিং। bytes, আট-বিট বাফার, ষোল মেগাবাইট ক্যাপ, hex আর base64 বিল্ট-ইন। টাইপ কাস্টিং: x as int মানে int(x), রাস্ট-স্টাইল, নিরাপদ ও স্পষ্ট। ঠিক চল্লিশটি রিজার্ভড কীওয়ার্ড, প্রতিটির নিজস্ব অর্থ, ভেরিয়েবলের নাম হিসেবে ব্যবহার করা যায় না: ঘোষণা, নিয়ন্ত্রণ, এরর, লজিক, OOP, জেনারেটর ও enum, কনকারেন্সি, মডিউল।

[[SLIDE 11]]
ক্র্যাশ নেই, finally বাদ যায় না। Null নিরাপত্তা: ?? দিয়ে null হলে বিকল্প মান, ?. দিয়ে null হলে নিরাপদে null রিটার্ন। যেমন user_name ?? Guest User, আর account?.wallet?.balance ?? 0.0। if x != null-এর ভেতরে x নিশ্চিতভাবে T, অর্থাৎ T? থেকে T। সিমান্টিক চেকার প্রমাণ করে যেখানে null সম্ভব নয়। এরর হ্যান্ডলিং: try ঝুঁকিপূর্ণ কোড, catch ধরে, finally সবসময়। finally কখনোই বাদ যায় না, return, break, continue বা throw থাকলেও না। ফাংশনাল স্টাইলে Option some/none আর Result ok/err, unwrap আর unwrap_or।

[[SLIDE 12]]
স্ট্রিং ও নিয়ন্ত্রণ প্রবাহ। স্ট্রিং ইন্টারপোলেশনে user আর score বসে; ব্র্যাকেটের ভেতরে স্পেস নিষিদ্ধ। ফলাফল format 88.6875 থেকে 88.69, tie-to-even রাউন্ডিং। মেথড: len, slice, upper, trim, split, replace, contains, repeat, format। সাবধান, ব্র্যাকেটে স্পেসসহ লেখা আক্ষরিক টেক্সট; লিটারেল ব্র্যাকেট চাইলে ব্যাকস্ল্যাশ বা র-স্ট্রিং। ইউনিকোড প্রস্তুত, ইমোজি এস্কেপ, আর স্পিডার শব্দের শেষ অক্ষর নেগেটিভ ইনডেক্সে r। নিয়ন্ত্রণ প্রবাহে if শুধু স্টেটমেন্ট নয়, এক্সপ্রেশনও: marks sixty-এর বেশি হলে Passed, নাহলে Failed। C-স্টাইল লুপ, list আর map ইটারেশন। প্রবাহ: শুরু, শর্ত, সত্য হলে বডি ও ফিরে আসো, মিথ্যা হলে বেরোও।

[[SLIDE 13]]
ফাংশন, ক্লোজার ও Match। ডিফল্ট প্যারামিটার, যেমন power-এ exp দুই। ক্লোজার বাইরের ভেরিয়েবল ধরে রাখে: make_acc-এর total। arrow দিয়ে filter, map, reduce চেইন। ফার্স্ট-ক্লাস ফাংশন মানে ফাংশন মান; ক্লোজার স্টেট মনে রাখে; map, filter, reduce চেইন করা যায়। সতর্কতা: ডিফল্ট প্যারামিটার items = খালি লিস্ট, প্রতি কলে নতুন কালেকশন তৈরি হয়, শেয়ার হয় না। Enum ও Match-এ কম্পাইলার নিশ্চিত করে: Command-এ Move, Rotate, Stop; guard if x == 0; বাদ দিলে কম্পাইল এরর, exhaustive match। ইউনিট ভ্যারিয়েন্ট Stop() লিখতে হয়, বন্ধনী বাধ্যতামূলক।

[[SLIDE 14]]
ক্লাস, ইনহেরিটেন্স ও ইন্টারফেস। Animal ক্লাসে public name, private energy, new কনস্ট্রাক্টর, speak মেথড। Dog ক্লাস Animal-কে extends করে, super(name) দিয়ে প্যারেন্টে দায়িত্ব দেয়, speak-এ super.speak-এর সাথে Woof যোগ করে। নিয়ম: ডিফল্ট ভিজিবিলিটি private, একক ইনহেরিটেন্স, self স্পষ্টভাবে প্রথম প্যারামিটার। interface Drawable-এ default মেথড বডি, বিমূর্ত ক্লাস, static মেথড।

[[SLIDE 15]]
কুড়ির বেশি কালেকশন ও লিনিয়ার অ্যালজেব্রা। list O(1) append, map O(1) এবং অর্ডার ধরে, set union/intersect, bag মাল্টিসেট, tuple অপরিবর্তনীয়, bytes বাইনারি, stack LIFO, queue FIFO, deque দুই মাথায়, heap O(log n), trie প্রিফিক্স, graph-এ Dijkstra বিল্ট-ইন, ring_buffer, linked_list, hash_table, bst, priority_queue, vec। স্থিতিশীল সর্ট sort_by, sorted_by, argsort — কম্পারেটর থ্রো করলেও ডেডলক বা প্যানিক নেই। লিনিয়ার অ্যালজেব্রায় ভেক্টর dot প্রডাক্ট 32.0, ম্যাট্রিক্সে det 10, inverse LU দিয়ে, solve। save_npy আর load_npy NumPy v1.0 ফরম্যাট, Python ইকোসিস্টেমের সাথে ডেটা বিনিময়। সীমা: এক কোটি ছয় লাখ সত্তর হাজার সাতশত ষোলটি এলিমেন্ট, ৬৪-বিট ফ্লোট বাফার।

সত্যিকারের সমান্তরাল, GIL নেই। spawn দিয়ে টাস্ক, M:N শিডিউলার, Thread এক, Thread দুই, দুইশত ছাপ্পান্ন পর্যন্ত। channel দিয়ে বার্তা, recv দিয়ে অপেক্ষা। কোনো গ্লোবাল লক নেই। async/await, task.join, mutex, atomic_int lock-free, এবং বিল্ট-ইন ডেডলক সনাক্তকরণ। Erlang ও Go-স্টাইল চ্যানেল।

[[SLIDE 17]]
সবকিছু বিল্ট-ইন, ছাব্বিশটি মডিউল। কনসোলে println, read_line, spid3rinfo। ফাইলসিস্টেমে স্ট্রিমিং হ্যান্ডেল, lock আর fsync। নেটওয়ার্কে http_fetch, UDS, native-tls। ম্যাথে random_bytes, CSPRNG। ক্রিপ্টো sha256, hmac, pbkdf2, ed25519, bcrypt, argon2। ফরম্যাট JSON, CSV, gzip, regex NFA। সময়ে সিভিল ক্যালেন্ডার আর strftime। পরীক্ষায় testkit, assert, mock। ছাব্বিশটি মডিউল সব বাইনারির ভেতরে: web, http, fastcgi, stats, mathx, toml, yaml, xml, tz পাঁচশত আশানব্বই IANA জোন, unicode, smtp, ftp, session, middleware, multipart, event, gen, bigint, decimal, rational, complex, semver, uuid। এক্সপোর্টেড ফাংশনে মডিউলের প্রিফিক্স থাকে, যেমন uuid.uuid_v4 আর toml.toml_parse। সততা-ঘোষণা: সব ক্রিপ্টো RFC টেস্ট-ভেক্টর দিয়ে যাচাইকৃত, কিন্তু এখনো স্বাধীন অডিট হয়নি; বড় প্রোডাকশনে অডিটেড প্রক্সি বা HSM ব্যবহার করুন।
