Imports & packages

Where code comes from

1The importing file's own directory
2SPID3R_PATH (; separated)
3./stdlib relative to working dir
4stdlib/ beside (or above) the executable
5vendor/ from nearest enclosing package
6stdlib table compiled into the binary
Disk always wins over the embedded table — a project can pin a patched standard library module.
Paths can't escape: absolute paths, drive letters, angle brackets or .. are rejected with invalid module path on every backend.
Signed & immutable: a SHA-256 checksum plus an Ed25519 signature · republishing a version is refused.
verify re-hashes vendored trees — editing one file fails the build gate.

Semver: ^1.2 · >=1.2.3 · =1.2.3 — plain major.minor.patch only, no pre-releases.

Lifecycle: add → tree → verify → publish → install
Ecosystem

Trust tiers T0–T3

Four routes — not the same authority.

T0Built-in stdlib — embedded, immutable, no disk override
T1Project .matrix files — same trust as your own source
T2Vendored packages — checksum-verified; verify re-checks
T3FFI (extern fn) — trusted code, native builds only
FFI is trusted code. extern fn runs outside every sandbox — use it only for your own trusted native libraries.
No install-time code. Dependency installation never executes package code — no Cargo-style build scripts. Deliberate, and a real security win.

Distribution

One self-contained file

spid3r compile app.matrix -o app.matrixc spid3r build app.matrix -o App.exe --release \ --icon app.ico --subsystem windows \ --bytecode app.matrixc --embed ui \ --bundle-runtime

Inside the payload

Compiled bytecode — no source shipped · UI assets served from memory · the bundled runtime is extracted on first launch.

What --bytecode buys: removes source text, symbols and string literals. What it doesn't: not secrecy — the VM is open source; it raises the cost from opening a text file to reverse-engineering bytecode.
XOR obfuscation ≠ secrecy. Don't put secrets in client binaries. One system dependency remains: the WebView2 runtime (default on Win11); everything else is linked statically.
Launcher trap: the working directory is not the program folder — point it at the app folder first, and launch helper processes hidden.

Enums & errors

Match, narrowing & guaranteed finally

enumMove(x, y)Rotate(degrees)Stop
return match (cmd) { Move(x, y) if x == 0 and y == 0 => "Hold", Move(x, y) => "Move to ({x}, {y})", Rotate(deg) => "Rotate {deg} deg", Stop => "Emergency Stop!", _ => "Unknown" };
Unit-variant trap: build with Stop(). Bare Stop is the constructor function, valid only in a pattern; as a value it yields “function does not support indexing”.
Scrutinee-driven exhaustiveness: a static enum match must cover every variant unless _ or a binding is present.
try { let val = int(s); } catch (err) { println("Caught: " + string(err)); return -1; } finally { println("Cleanup: completed"); }
finally is guaranteed — even when try issues return, break, continue, or an unhandled throw.

Option: some(v) / none · Result: ok(v) / err(e) · all filesystem primitives return result.

Clean error state: on a throw, the VM restores the stack exactly — every catch sees a clean state.

OOP

Classes, inheritance & interfaces

class Animal { public let name; private let energy; public fn new(name: string) { self.name = name; self.energy = 100; } public fn speak(self) -> string { return self.name + " makes a sound"; } }
class Dog extends Animal { public let breed; public fn new(name: string, breed: string) { super(name); // delegate to parent ctor self.breed = breed; } public fn speak(self) -> string { return super.speak() + " -> Woof!"; } }
Core rules: explicit self as first parameter · default visibility is private · single inheritance via extends · super(args) and super.method() · abstract class · public static fn.
Interfaces: interface Drawable { fn draw(self); fn area(self); } can carry default method bodies; class Circle implements Drawable dispatches through a heterogeneous list.
Gradual unchecked case: let c: C = C(); c.secret is rejected when the receiver's class is statically known; untyped let c = C(); c.secret is a gradual unchecked case.

Security honesty

The cryptography trust statement

Not independently audited. The crypto primitives (sha256/512, hmac, pbkdf2, ed25519, bcrypt, argon2) and the TLS 1.3 client are pure Rust with zero dependencies — verified by internal RFC test vectors and negative/malleability tests, but not formally proven side-channel hardened. External review is pending.
For high-stakes production: terminate TLS or run secret-key operations behind an audited reverse proxy or HSM.

Ed25519

Constant-time cswap Montgomery ladder, canonical S < L, small-order-key and off-curve rejection. Verification is strict but not constant-time.

Randomness discipline

Only random_bytes(n) is cryptographic. random_int/float/normal are clock-seeded xorshift — never suitable for tokens.

jwt_verify: constant-time with 60-second exp/nbf skew, but checks HS256 only and doesn't pin alg to a policy — don't feed it tokens from an issuer you don't control.
Constant-time by construction: bcrypt_verify and secure_compare.
